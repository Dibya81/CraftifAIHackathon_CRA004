# SiteSentinel

PPE and hazard-zone safety intelligence on CraftifAI PipeGen. Embedded SF hackathon, Track A.

## Docs
- `docs/PRD.md`: requirements, acceptance criteria, 8-week plan
- `docs/ARCHITECTURE.md`: components, data flow, topics, rule design
- `docs/DESIGN.md`: dashboard design system and screens
- `docs/diagrams/architecture.svg`: architecture diagram

## Quick start (once implemented)
1. Install PipeGen v0.5.1 and generate the pipeline from `pipegen/requirement.md` into `pipegen/export/`.
2. `pip install -r requirements.txt`
3. `./scripts/run_demo.sh`
