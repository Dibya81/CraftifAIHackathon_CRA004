# PipeGen workspace
1. Install PipeGen v0.5.1 (`pipegen --version` must print 0.5.1).
2. Paste `requirement.md` into stage 1, then walk Pipeline IR, Model, Compiler, Run.
3. Export into `export/`. Screenshot the Pipeline IR graph and the TensorRT speed report into `../reports/`.
4. Build FP16 and INT8 variants and save both speed reports.
